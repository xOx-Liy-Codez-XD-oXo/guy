# i wanna be the guy
animated music thing for the wii

## compiling
you need libogc 2.11. any newer will break application features. use libdvm i dont think libfat works
```
git clone https://github.com/xOx-Liy-Codez-XD-oXo/guy
cd guy
make
make pack
```
